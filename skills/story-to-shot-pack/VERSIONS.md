# Public version history

## v0.1.0 — 2026-10-19
First public process for extracting ordered visual shots, dialogue, static prompts and motion prompts from an already-written drama script.

## v0.2.0 — 2026-10-19
Added cast and clue continuity ledger, exact frame ranges, contiguous timeline requirements, audio/caption fields, example JSON and an offline validator.

Both are genuine **new public editions**, not backdated copies of private historical versions. No claim is made about installing them in an agent host or rendering a video.
