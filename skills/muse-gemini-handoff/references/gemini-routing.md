# Routing tasks to Gemini-related capabilities

This routing advice is a portable summary of dated workflow concepts, **not** a live statement of Google entitlements. Check the product UI and official current docs before treating a feature as available.

| Work | Route to verify on receiving account | Evidence required |
| --- | --- | --- |
| Light fact questions and short copy | Appropriate current Gemini chat mode | Model selection, answer and review |
| Complex story logic or production requirements | Higher-reasoning Gemini mode if supported | Locked inputs and explicit contradictions review |
| Character sheets or reference images | Available image generation/editing UI | Prompt, source assets, saved image and visual QA |
| Music and narration | Available creative audio feature or another authorized tool | Prompt, downloaded audio, playback test and rights |
| Vertical video shots | Flow/video-generation feature if provisioned | Orientation, length, credits, actual clip QC |
| Structured APIs and application prototypes | AI Studio only if its current terms and billing are acceptable | Distinguish UI entitlement from API pricing |

For detailed prompt patterns, browser checks, downloading and quota accounting use sibling Skills `gemini-full-stack-mastery` and `gemini-window-mastery` rather than duplicating their dynamic feature matrix here.

A Gemini generation is not completion of a multi-agent task until its file is saved, independently reviewed where required, and correctly handed off or published.
