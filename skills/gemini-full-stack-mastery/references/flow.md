# Flow: AI video clip production

Field-tested workflow from the original 2026-10-17 source. Current feature availability and credit prices should be read from Flow itself, not copied from an old plan table.

## Production sequence

1. Break a script into short, independently describable shots with subject, action, motion, camera, time-of-day, mood, duration and dialogue/audio requirement.
2. Specify intended output ratio (for mobile vertical distribution, often 9:16), target resolution and continuity constraints before generation.
3. Generate one representative shot first. Verify the model produces moving action, not a static frame with incidental zoom.
4. Inspect character consistency, scene geography, legibility, camera continuity, voice/audio and duration; revise prompt before batch generation.
5. Download immediately, play the real file, measure resolution and duration. Track `generated` versus `downloaded_verified` counts.
6. Store the accepted take, prompt, model/date and remaining-shot queue outside ephemeral UI history.

**Quota:** read account's real current credits, allocation, expiration and per-job cost. A figure quoted in the historical v1 source is not a current entitlement guarantee. Confirm rights, branding and distribution requirements before publishing.
