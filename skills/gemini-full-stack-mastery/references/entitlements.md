# Feature and entitlement checklist (source observations dated 2026-10-17)

The private v1 distinguished **free / subscription-included / higher-plan / API-billing-required** capabilities. The precise product tiers, model names, availability, reset windows and limits are subject to change. This public checklist deliberately omits personal account entitlement screenshots and identifiers.

| Surface | Capabilities to verify in your current account | Evidence to collect |
| --- | --- | --- |
| Gemini web | text models, reasoning level, document upload, image/video/music, research, custom skills | model dropdown, plan indicator, current available actions |
| Google AI Studio | text, image, video, audio / TTS / music playgrounds | selected model, whether an API key or paid project is required for the *exact* action |
| Flow | shot creation, video format, monthly credits or limits | real available credit panel, length/ratio choices, export |
| NotebookLM | notebook and source limits, summary formats, audio features | current account limits in official help or account UI |
| Experimental/Labs | account/region-specific toggles and changes | availability and observed behavior, not a blanket entitlement claim |

**Historical insight:** In the original October tests, a model card labeled `Paid` in an API selector did **not always** mean the interactive page required payment, while some other models did require a billing-enabled key. Check separately **API billing**, **browser playground availability** and **subscription quota**.

Never present the source's dated allowance figures as evergreen guarantees. For a publishable comparison, record `surface | account plan (redacted) | date | UI observation | official documentation URL | status`.
