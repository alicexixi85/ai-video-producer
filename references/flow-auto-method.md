# Flow 全自动操作法

> 用户零参与原则下，Flow 浏览器操作全部由 agent 完成。经 EP1 实战验证稳定。

## 中转复制法（填长提示词）

Flow 的提示词编辑器直接粘贴长文本不稳定（会被截断/吞字符）。稳定流程：

1. 在 Flow 页面找一个**页面搜索框**（或任何普通文本输入框）做中转
2. 把完整提示词粘贴进搜索框（纯文本输入框不吞字符）
3. 全选 → 复制
4. 粘贴到 Flow 的提示词编辑器
5. 核对编辑器内文本完整（快速扫一眼首尾）

## 生成参数

- 模型：Veo 3.1 **Lite**（验证用；效果不够再上 Fast/Quality）
- 时长：8 秒；画幅：**9:16**；每条 10 点
- 一次只生成一条，下载验片通过后再下一条

## 账号与项目

- 默认用用户 Google Pro 账号的 Flow 点数
- 点数不足 → 切第二个 Pro 账号（信息向用户要）→ 都不足 → 向用户汇报，由用户决定
- **绝不提 API 付费路线**，绝不查 Veo API 价格
