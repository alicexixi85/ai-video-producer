# Creative workflows (field notebook generalized)

## Images

1. Select an actual image-generation feature visible in the UI; do not assume ordinary text chat always invokes it.
2. Draft the intended subject, composition, mood, visual style, continuity constraints and output ratio. Record the prompt and selected mode.
3. Generate a low-cost draft where the product supports it; inspect faces, hands, text, perspective, framing and original concept fit.
4. For a hero frame, use the UI's higher-quality regeneration or edit route **only when the current product provides it**. Verify that the regenerated file was downloaded, not merely rendered in the page.
5. For multi-image stories, reuse a fixed character description and references; verify consistency across shots.

## Music

1. Write a music brief first: genre, mood, tempo, instruments, voice/no-voice preference, structure and usage rights.
2. Use a music generation feature actually available to the current user; retain the prompt and generation date.
3. Listen to the result, check length, clipping, voice issues, file format and permitted publishing conditions, then save locally.

## Video

1. Where supported, choose portrait 9:16 before generation and record the model/quality tier and task-specific credit cost shown in the UI.
2. Make each prompt describe one shot: action, environment movement, camera movement, lighting, duration and transition.
3. Inspect temporal continuity, character consistency, facial/body anomalies, frame rate, dimensions and audio after downloading. An online preview is not a final QC pass.
4. Track the credit consumption observed; avoid assuming another team's or another account's quota is shared or transferable.

## Story-to-production packs

1. Provide the completed script, reference characters and locked story rules.
2. Ask the model to identify plot logic, clue continuity, awkward cuts and unfilmable abstractions before drafting the shot list.
3. Draft: cast cards, numbered shots, camera types, action, dialogue, image/video prompts, sound cues and quality checklist.
4. Save long outputs in small named segments, verify each file exists, then assemble a consistent package.

These are methods adapted from the source v1.1 guide; they do not certify the quality of any unreviewed generated media.
