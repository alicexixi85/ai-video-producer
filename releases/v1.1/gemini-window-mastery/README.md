# Gemini Window Mastery — public v1.1

A portable Agent Skill based on a dated **2026-10-17** operational handbook for Gemini web window tasks: session/profile verification, model routing, quota observations, image/music/video work, production-pack review, saving artifacts, and installation tests.

**Install:** copy this whole `gemini-window-mastery` folder into a compatible skills directory, ensuring all four `references/` files remain alongside `SKILL.md`. Actual Gemini product availability and invoking a skill depend on your current account and client UI.
