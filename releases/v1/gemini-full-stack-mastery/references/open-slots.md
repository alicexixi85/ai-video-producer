# Open questions from the 2026-10-17 source

This is a **public issue checklist**, not an assertion that a feature is absent.

- Which historical model names and reasoning controls still appear in each plan/region?
- Does Gemini's skill UI support explicit invocation, automatic matching, both, or a different flow now?
- How is a `Paid` model card related to an available browser playground action versus API billing in the current release?
- Which image regeneration actions are time-sensitive or disappear when revisiting outputs?
- What are the actual current quota units and reset windows for each surface and account type?
- Can output files (especially audio and video) be downloaded through the browser environment in use? Verify bytes, not click events.
- What are the current supported lengths, output resolutions and aspect ratios for music and video?
- Are NotebookLM and Labs entitlements currently documented, and can source citations be independently rechecked?

Close an item only with `observation date + reproducible steps + current official URL or direct UI evidence + limitations`.
