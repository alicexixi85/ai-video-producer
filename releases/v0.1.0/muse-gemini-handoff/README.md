# Muse + Gemini Handoff — a general-purpose multi-agent operations Skill

A stand-alone **public packaging candidate v0.1.0**, derived from an earlier (2026-10-12) multi-agent handoff design and a (2026-10-14) shared-folder operations manual. Those source documents described design and team procedures; they **did not establish a live universal Muse/Gemini integration**. This Skill combines their transferable ideas into one portable, file-first protocol.

Install by copying the complete `muse-gemini-handoff/` folder into a compatible Agent Skills location. Then configure your **own** shared storage/queue, real recipient sessions, authentication and permission rules; this package contains no host hooks or credentials. For Gemini feature instructions pair with the separate `gemini-full-stack-mastery` and `gemini-window-mastery` Skills.
